Achievement Tier Generator

LifeUp doesn't have a built-in achievement template feature yet, but its achievement API can create achievements directly. This page builds one tap-to-create link per tier from a single template, so you fill the form once instead of copying and editing 4 achievements by hand. Open this page on your Android device — the generated links only work where LifeUp is installed.

01 Saved templates

Templates are stored only in this browser (localStorage), not sent anywhere.

02 Shared settings

Applies to every tier below. IDs are found via Settings → Labs → Developer Mode, then opening the relevant detail page in LifeUp.

This is what's actually used to file the achievements below. If the category doesn't exist yet, tap the generated link above first, then check Developer Mode for its new ID and paste it here — a webpage can't read the ID back automatically, only a native app integration can.

03 Variables

Placeholders you can reuse in tier names/descriptions below, written as {key}.

04 Tiers

One achievement per tier. Reference your variables with {name}, {something}, etc.

05 Generate

Unofficial community tool · built against the LifeUp API as documented at docs.lifeupapp.fun. Not affiliated with LifeUp / Ayagikei. No data leaves your browser.
